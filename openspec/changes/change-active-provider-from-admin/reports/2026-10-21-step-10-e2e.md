# Step 10: end-to-end test in the browser (JOS-171, change-active-provider-from-admin)

Date: 2026-10-21. Branch `feature/jos-171-change-active-provider`. Driven with Chrome (the Claude in Chrome tools, not Playwright MCP). The real backend ran on port 3180 with the same launcher as step 9 (two stub adapters per stage, a scratch store and projects folder, `ADMIN_PASSWORD` set to a scratch value) and the real frontend ran on Vite at port 5173 with `VITE_API_BASE=http://127.0.0.1:3180`. Port 3100, the default backend port, was already in use by another process, so it was left alone.

## 10.1 Applicability

A new `/admin` section: the step applies.

## 10.2 The `/admin` page

| Step | Observed |
| --- | --- |
| Open `/admin` with no password | Only the password form and Unlock; no "Active providers" section, no selects |
| Enter the password and unlock | "Active providers" with five rows (Reasoning, Voice, Alignment, Image, Video), each select on the settings default and each row saying "from settings files" |
| Change Video to `stub-b` | The select shows `stub-b` and the row says "set on /admin"; the other four rows are unchanged |
| Reload `/admin` and unlock again | Video still `stub-b`, "set on /admin" (the page asks for the password again: it is never stored) |

## 10.3 Sessions before and after the change

- Video was set back to `stub-a` on the page; Session A was started (by `POST /sessions`) and finished: both scenes `video_provider = stub-a`.
- Video was set to `stub-b` on the page; Session B was started from the regular page's form (the privacy prompt was dismissed with "Not now") and finished with the final video ready: both scenes `video_provider = stub-b`. Session A stayed on `stub-a`.

**Finding (not a defect of this change, noted for the follow-up ticket):** the scene diagnostics print "Unknown provider" for a provider id the interface has no display name for, so `stub-a` and `stub-b` show that way (the voice, image and clip lines). With the single real adapter per stage the names show as before. A second real provider needs its display name added there (`backend/src/stageDiagnostics.ts` is the place to look).

## 10.4 Restore

Both servers were stopped, the scratch store and projects folder were deleted, ports 3180 and 5173 are free again, `backend/data/` does not exist and `git status` is clean.
