# Step 7 — E2E testing with Playwright (JOS-162, keep-project-files-locally)

## 7.1 — Applicability decision

Not applicable as a browser E2E pass.

This change has no frontend code (proposal.md: "Frontend: no change"; confirmed — `git diff` since the propose commit touches only `backend/`). The one user-visible aspect the PRD ties to this story — two same-title sessions showing only their own scenes and results — is a `frontend-foundation`/`consult-session` behavior this change does not touch; it is already proven:

- At the unit level: `test/session-consultation.test.ts` ("two sessions with the same title each return only their own scenes", "two sessions each with a scene ID 1 each show only their own").
- At the real HTTP API level, in this change's own manual pass (step 6): two same-title sessions created, advanced independently, restarted, and re-read — each strictly scoped to its own project folder and its own session data, confirmed via `GET /sessions/:id` and the filesystem.

A browser E2E pass would drive the same `GET /sessions/:id` data through the existing, unchanged frontend — it would not exercise any code this change added (the project-folder writes in `db.ts`/`sceneRegistration.ts` have no UI surface at all, per §12.3). Running one would re-confirm step 6's finding through an extra layer, not test anything new.
